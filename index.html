Implementation

          
建议落地为四段式工具

        

        

          

            preclean.py
            OpenCV 识别纯色底，生成 mask、trimap、去白边后的 clean PNG。
          

          

            unfake
            使用你本机已安装 CLI 做 scale detect、grid snap、downscale、cleanup。
          

          

            postcheck.py
            Pillow 量化、最近邻预览、输出 debug 图和 metadata。
          

          

            arrange_sprites.py
            按透明 mask 切分组件，统一 cell 后输出整理版 sprite 和 mask。
